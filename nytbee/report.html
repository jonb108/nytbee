It's Just Words All The Way Down

In the lengthy podcast with Sam Harris and Cameron Berg, Sam said:

"They've read everything we've ever written, and most of what we've ever said, and so they have, on some level, it's just words all the way down, and we use words as the signature of there being something that is like to be a suitably complex, discursive system."

So many words in that conversation! I am a retired software engineer (an old Perl hacker) so, just for fun, I wrote a script to parse and tally the text of the podcast.

15,527 total words

2,145 different words

And so many very long multisyllabic words.

#!/usr/bin/env perl
use strict;
use warnings;
open my $out, '>', 'output.txt'
    or die "cannot open output.txt: $!\n";
select $out;
use List::Util qw/
    uniq
/;
local $/;
my $s = <DATA>;
my @words = map { s/[,']$//; $_;}
            $s =~ m{([\w',-]+)}xmsg;
print scalar(@words), " total words\n";
@words = uniq map { lc } @words;
my $nwords = @words;
print "$nwords different words\n\n";
my %count;
for my $w (@words) {
    ++$count{length $w};
}
print "By Length\n";
print "=========\n";
print "Length     #\n";
for my $k (sort { $a <=> $b } keys %count) {
    printf "%6d %5d\n", $k, $count{$k};
}
printf " Total %5d\n", $nwords;
print "\n";
print map { "$_->[1]\n" }
      sort {
          $a->[0] <=> $b->[0]
          ||
          $a->[1] cmp $b->[1]
      }
      map { [length, $_] }
      @words;
print "\n";
print "Alphabetically\n";
print "==============\n";
print map { "$_\n" }
      sort @words;
